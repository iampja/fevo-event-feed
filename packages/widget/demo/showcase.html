Event Feed Widget

The FEVO widget can be embedded at any size — from a narrow sidebar card to a full-page event directory. Each includes contextually appropriate filters.

Sidebar Widget

1 column · 380px

Fits in a narrow sidebar or rail. Single city filter keeps it compact.

Preview max-width: 380px
Embed Code 
<div class="fevo-event-feed"
     data-theme="light"
     data-columns="1"
     data-max-cards="3"
     data-geo="auto">
</div>
<script src="https://fevo-event-feed-widget.onrender.com/event-feed-widget.js"></script>
